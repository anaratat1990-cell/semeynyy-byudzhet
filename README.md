# Вместе копим

Бесплатное семейное PWA-приложение для учёта бюджета двух человек. Данные хранятся в браузере устройства: сервер, учётная запись и подписка не нужны.

## Установка на телефон

1. Опубликуйте эту папку на бесплатном HTTPS-хостинге (например, GitHub Pages или Cloudflare Pages).
2. Откройте выданную ссылку на телефоне.
3. В Chrome на Android нажмите меню → **Установить приложение**; в Safari на iPhone — **Поделиться** → **На экран «Домой»**.

После установки приложение открывается отдельно от браузера и работает без сети. Для работы в браузере на компьютере откройте `index.html`.

## Что уже есть

- бюджет Анны и Михаила: общие доходы и расходы;
- категории: продукты, такси, бензин, лекарства, кредиты, связь, подписки и другие;
- добавление операций и целей накоплений;
- расчёт свободной суммы: доходы − расходы − резерв 10 %;
- цели: путешествие, квартира, депозит;
- аналитика расходов по категориям и участникам;
- сохранение внесённых данных на устройстве.

## Банковские карты

Экран подготовлен для будущего подключения карт. Реальная автоматическая загрузка операций должна выполняться только через официальные API банков или лицензированного агрегатора с защищённой авторизацией. В этой локальной бесплатной версии операции добавляются вручную; это не требует передачи финансовых данных третьим лицам.
